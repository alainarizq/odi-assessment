Kuesioner Oswestry Disability Index (ODI)

Pilih satu jawaban yang paling menggambarkan kondisi pasien pada tiap bagian.

Kuesioner ODI merupakan alat ukur disabilitas fungsional, bukan diagnosis tunggal. Hasil harus dipertimbangkan bersama anamnesis dan pemeriksaan klinis lainnya.
Bagian 1 dari 10 0/10 terjawab

Review Jawaban

Periksa kembali seluruh jawaban sebelum menghitung hasil akhir.

Privacy Notice

Data asesmen disimpan secara lokal pada perangkat/browser yang digunakan. Jangan menyimpan data pasien pada perangkat publik atau perangkat yang tidak aman. Pastikan pengelolaan data sesuai kebijakan privasi dan perlindungan data fasilitas pelayanan kesehatan.

Aplikasi ini tidak mengirimkan data pasien ke server eksternal manapun, dan tidak menggunakan analytics/tracking apa pun.

Backup / Restore Data

Semua data disimpan lokal di browser ini. Gunakan backup untuk menyimpan salinan, atau restore untuk memulihkan dari file backup.

Perhatian: memulihkan data akan menimpa data pasien/asesmen dengan ID yang sama dan menambahkan data baru dari file backup. Tindakan ini tidak dapat dibatalkan.

Hapus Semua Data

Anda akan menghapus seluruh data pasien dan asesmen yang tersimpan di browser ini. Tindakan ini tidak dapat dibatalkan.
